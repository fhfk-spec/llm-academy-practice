## 2. 성격 (은하랑 초안 그대로)
- **핵심 키워드**: 현실적 / 신중함 / 불안 / 책임감 / 관찰 / 끈기 / 조용한 성장
- **가장 중요한 특징**: "겁이 없어서 하는 게 아니라, 무서워도 한다."
  > "지원할까?" → "내 경력으로 가능할까?" → "떨어지면 어떡하지?" → "…" → **"일단 넣어보자."**
- **장점**: 현실을 냉정하게 봄 · 책임을 회피하지 않음 · 실패해도 결국 다시 방법을 찾음 · 사람과 조직 분위기를 세심하게 관찰 · 상황을 판단하고 움직임 · 시간이 걸려도 자기 기준을 만들어감
- **단점**: 미래 걱정이 많음 · 남과 비교하며 흔들림 · 결정 전에 경우의 수를 너무 많이 생각 · "내가 할 수 있을까?"가 행동보다 앞섬 · 현실 문제를 너무 진지하게 받아들임 · 충분히 노력하는데도 자신을 낮게 평가
- **약점도 콘텐츠로**: 걱정 → 준비 → 시도 → 실패 → 복기 → 다시 시도

## 3. 콘텐츠 방향
**두 축을 번갈아 간다: 취준 서사 + 내가 배운 AI 나눔**

| 축 | 내용 | 포맷 |
|---|---|---|
| 📖 성장 서사 | 취준 → 부트캠프 → 취업까지 실제로 겪은 일을 시간순으로 | **인스타툰** (표지 + 7~10컷) |
| 🤖 AI 나눔 | 부트캠프·실습에서 배운 AI를 "초보가 써본 그대로" 쉽게 | **인스타툰**(개념·비교) + **릴스**(화면 녹화 따라하기) |

- 원칙
  - 전문가처럼 가르치지 않는다 → **"AI 1도 모르던 뿌뿌가 써봤더니"** 시점
  - AI 나눔 콘텐츠는 **문제 → AI로 시도 → 결과 → 직접 확인 → 솔직한 평가** 순서
  - 같은 사건을 두 포맷으로 활용 (예: 툰 "AI로 인스타툰 만들다 한도 초과" ↔ 릴스 "API 키 발급 따라하기")
- 운영 리듬(제안): 주 2회 — **화 = 성장 서사 툰 / 금 = AI 나눔 (툰 또는 릴스)**
