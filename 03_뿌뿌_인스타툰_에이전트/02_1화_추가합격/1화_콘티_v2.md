# 뿌뿌 1화 콘티 v2 — "6개월째 탈락 중인 취준생에게 걸려 온 전화 한 통"

- 구성: 표지 + 9컷 (1080×1350, 4:5)
- 의상: 시안 기준 임시값 (연베이지 상의 + 회청색 바지) — 브랜드 컬러 확정 후 교체
- 감정선: 탈락·무기력 → 생계(행사팀장, 매장 확장 준비) → **전화** → 얼떨떨·이메일 재확인 → 실장님께 퇴사 연락 → 환호 → 인수인계(겉은 차분, 속은 신남) → 몸은 뻗었지만 마음은 행복
- v1 대비 변경: 구석에 앉은 컷 삭제, 문자 → 전화, 이메일 재확인·실장님 연락·인수인계·집에서 뻗는 엔딩 추가, 행사 = 매장 확장 오픈 준비(물류 입고·배치)
