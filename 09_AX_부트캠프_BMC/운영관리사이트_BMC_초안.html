2가치 제안

반복 운영업무를 자동화해서 운영진의 시간을 아끼고, 누락·실수를 줄인다.

  • 출결 (MVP): 강의장 와이파이에 폰을 연결해야 입실·퇴실 2회 인증 가능 → 시간 자동 기록·업로드, 출결률 자동 계산. 와이파이 밖(데이터 사용)에서는 인증 불가로 대리출석 방지
  • 증빙서류 현황 (MVP): 병결·예비군 서류 제출 여부만 사이트에서 관리, 미제출자 자동 알림. 서류 원본은 사이트에 저장하지 않고 별도 보관
  • 문의·요청: 공지 페이지로 문의 접수 → 유형 자동 분류, 자주 묻는 질문은 자동 답변, 처리 상태 추적
  • 행정: 비용 관련·서류 제출 안내 자동 발송, 제출 현황 관리
  • 성과자료: 정기 운영자료 · 성과자료 자동 취합, 보고서 초안 생성

→ 운영진은 사람만 할 수 있는 일(수강생 상담·케어)에 집중

5수익원 · 성과 지표

팀 프로젝트 단계에서는 매출보다 "효과 지표"로 가치를 증명

  • 운영업무 시간 절감 (예: 주당 몇 시간 줄었는지)
  • 증빙서류 누락률 · 문의 응답시간 감소
  • 성과보고 작성 시간 단축, 정확도 향상
  • 외부 판매 없음: 교육회사 내부 운영시스템으로만 사용 → 가치는 내부 효율화로 측정

결정 사항 · 테크팀과 확인할 질문

결정됨

  • MVP: 출결관리 + 증빙서류 현황
  • 증빙서류 원본은 사이트에 저장하지 않음 (별도 보관)
  • 출결: 강의장 와이파이 연결 시에만 입실·퇴실 2회 인증
  • 보류 현장 QR코드 인증 방식 (도입 여부 미정)
  • 내부 운영시스템 전용, 외부 판매 없음

테크팀 확인

  • 와이파이 확인 방법: 웹페이지는 폰이 어떤 와이파이에 붙었는지 직접 못 읽음 → 접속 IP가 강의장 공인 IP인지 서버에서 확인하는 방식 가능한지 (유력, 확정 아님)
  • 보류 QR 도입 시 사진 공유 방지 방법 (QR 주기적 변경 등)
  • 퇴실 인증을 안 하고 간 경우 처리 규칙
  • 행정 처리 중 "돈 문제"는 구체적으로 어떤 업무? (2차 기능 때 정리)

검증할 가설

  • 운영매니저는 출결 계산·서류 취합에 매주 상당한 시간을 쓴다
  • 수강생 문의의 상당수는 반복되는 같은 질문이다
  • 서류 미제출 알림을 자동화하면 누락이 줄어든다
  • 성과자료 취합은 여러 파일을 손으로 모으는 작업이라 자동화 효과가 크다

→ 운영매니저에게 "지금 이 업무에 일주일에 몇 시간 쓰는지" 물어보면 지표 기준선이 생겨요.
