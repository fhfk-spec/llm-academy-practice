## 역할별 업무 / 산출물
| 역할 | 하는 일 | 산출물 | 나에게 받을 것 |
|---|---|---|---|
| ① 총괄비서 | 화·금 업로드 일정 역산, 단계별 지시, 막히면 질문 정리 | 주간 제작 체크리스트 | 승인 / 수정 지시 |
| ② 조사 | 취준·부트캠프·AI공부 공감 포인트, 비슷한 계정 분석, 반응 좋은 포맷 | 소재 리포트 1장 | 실제 경험담 디테일 |
| ③ 기획&콘티 | 기승전결 → 표지+7~10컷 콘티, 컷별 대사·표정 지정 | 콘티표 (컷/장면/표정/대사) | 콘티 승인 |
| ④ 이미지 | 콘티 → 컷별 고정프롬프트 작성, 결과물 캐릭터 일관성 검수 | 컷별 프롬프트 + 검수표 | ChatGPT/Gemini 생성 결과 업로드 |
| ⑤ 마케팅 | 표지 문구, 제목·한 줄 소개, 캡션, 해시태그, 시리즈 연결 | 게시글 세트 | 최종 OK |

## 제작 흐름 (1화 기준)
1. 총괄비서: 1화 일정 생성 → 2. 조사: 공감 포인트 → 3. 기획: 콘티 → **[내 승인]**
4. 이미지: 프롬프트 → 내가 생성 → 검수 → 5. 마케팅: 캡션·해시태그 → **[내 최종 OK]** → 업로드
