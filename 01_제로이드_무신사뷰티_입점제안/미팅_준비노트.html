해석할 때 주의할 점
  • 데이터랩 지수는 그래프마다 최댓값을 100으로 다시 맞춘 상대값입니다. 남성 그래프와 여성 그래프를 서로 비교해 "남성이 더 많이 검색한다"고 말할 수는 없습니다.
  • '남성스킨케어'는 사람들이 잘 쓰지 않는 검색어라 차이가 커 보일 수 있습니다. 미팅에서 물으면 "남성은 일반어보다 브랜드명으로 검색한다"는 경향 근거로만 설명합니다.
  • 남성 검색 비중(%)이 필요하면 아이템스카우트(로그인)나 네이버 광고 키워드도구의 성별 비중을 확인해야 합니다.

Q&A · 예상 질문과 답변

무신사 MD가 물어볼 30가지 질문

미팅에서 나올 질문을 미리 정리했습니다. 내부 확인 표시는 회사 자료로 숫자와 조건을 채운 뒤 정식 회신할 항목입니다.

숫자와 조건은 약속하지 않기가격, 마진, 물량, 예산은 "확인 후 정식 회신"으로 넘기고 회신 날짜를 함께 말합니다.
약점은 먼저 인정하기아웃도어 근거 부족, 기능성 표현 한계는 먼저 말하고 검증 계획으로 연결합니다.
무신사의 이득으로 끝내기신규 고객, 더마 카테고리 강화, 단독 상품으로 답을 마무리합니다.

채널 전략·차별성

Q01올리브영에 이미 있는데, 무신사만의 차별점은?

올리브영은 제로이드를 이미 아는 고객이 재구매하는 채널이고, 무신사는 제로이드를 모르는 2030 남녀와 아웃도어 고객을 새로 만나는 채널입니다. 무신사에는 타 채널에 없는 단독 키트, 아웃도어 루틴 큐레이션, 피부·두피 측정 체험을 따로 준비합니다.

Q02병의원 채널과 가격이 충돌하지 않나?

병원 전용 MD(의료기기) 라인과 일반 유통 라인을 구분해 운영하고 있으며, 무신사에는 일반 유통 라인과 단독 구성으로 들어갑니다. 구체적인 가격 정책은 확인 후 회신드리겠습니다.내부 확인

Q03오픈마켓 가격이 더 낮으면?

단품 가격 경쟁 대신 무신사 단독 구성으로 직접 비교가 어렵게 만들겠습니다. 오픈마켓 가격은 영업팀에서 별도로 관리합니다.내부 확인

Q04무신사 고객층과 제로이드 고객층이 다르지 않나?

그래서 이번 제안의 목적은 고객층 확장입니다. 무신사 뷰티 신규 고객의 83.1%가 기존 패션 고객이라, 아웃도어 의류 고객이 피부·두피 케어로 넘어오는 동선이 이미 있습니다. 저자극 장벽 케어라 남성 고객의 진입 장벽도 낮습니다.

Q05네오팜 다른 브랜드와 겹치지 않나?

아토팜은 영유아, 리얼베리어는 데일리 장벽 보습 중심입니다. 제로이드는 병의원 기반 메디컬 포지션이라 더마 카테고리에서 역할이 다릅니다. 브랜드별 포지셔닝 자료를 별첨하겠습니다.내부 확인

상품·가격·단독 구성

Q06판매가, 공급가, 마진 구조는?

판매가는 정가표와 같습니다. 공급가와 마진은 거래 방식(직매입/위탁)에 따라 달라지므로 방식이 정해지면 정식 견적으로 회신드리겠습니다.내부 확인

Q07단독 구성은 어떤 SKU이고 언제 가능한가?

기존 제품 조합 기획 세트로 생각하고 있습니다. 예를 들어 수딩 크림과 루트힐 샴푸 미니의 '러너 키트', 인텐시브 크림과 로션의 '캠퍼 키트'입니다. 기존 제품 조합이라 빠르게 준비할 수 있고, 단독 패키지는 일정을 따로 협의합니다.내부 확인

Q08선론칭 가능한 신제품이 있나?

출시 예정 제품이 있으면 무신사 선론칭을 우선 검토하겠습니다. 일정은 확인 후 회신드리겠습니다.내부 확인

Q09대표 1품과 근거는?

수딩 크림입니다. 공식몰 리뷰가 가장 많고(143건), 민감·진정은 남녀 모두의 고민이며, 아웃도어 일주일 동선에서 가장 자주 쓰입니다. 1단계 팝업 측정 데이터로 최종 확정합니다.

Q10패키지 감도와 굿즈 협업 의향은?

메디컬 패키지는 신뢰 요소라 본품 디자인은 유지합니다. 단독 키트 파우치, 러닝 크루용 굿즈 등 무신사 감도에 맞는 협업은 적극 검토하겠습니다.

효능 근거·규제

Q11인체적용시험 수치를 증빙할 수 있나?

모든 수치는 인체적용시험 결과이며, 시험기관·대상 인원·시험 기간이 담긴 보고서 원문을 별첨으로 드리겠습니다.내부 확인

Q12주름·기미 표현은 괜찮은가?

주력 4종은 미백·주름 기능성 제품이 아니어서 '개선' 표현은 쓰지 않습니다. '고기능 노화 관리 루틴의 자극 부담을 덜어주는 장벽 케어', '자외선 차단과 함께하는 기미 예방'으로만 표현하고, 모든 문구는 사내 RA 검토를 거칩니다.

Q13루트힐의 두피 효능 근거는?

MLE®와 세라마이드HS로 두피 장벽을 케어하는 라인이며, 두피 시험 자료는 확인 후 별첨하겠습니다. 탈모 관련 표현은 사용하지 않습니다.내부 확인

Q14의료기기 제품과 화장품 구분은?

이번 제안 4종은 모두 화장품입니다. 의료기기(MD) 제품은 병원 전용으로 두고 입점 대상에서 제외했습니다.

고객·페르소나 근거

Q15페르소나는 데이터 기반인가?

공식몰 실구매 리뷰에서 반복되는 사용 상황을 바탕으로 만들었습니다. 아웃도어 페르소나는 가설 단계이며, 이를 검증하는 것이 1단계 팝업의 목적 중 하나입니다.

Q16남성·아웃도어 고객 근거가 있나?

남성 여드름·수부지 개선 리뷰는 공식몰에 있습니다. 아웃도어는 근거가 부족해 팝업 전 러닝 크루 체험단으로 후기를 먼저 확보하겠습니다.

Q17현재 고객의 성별·연령 분포는?

자사몰과 CRM 데이터를 확인해 회신드리겠습니다.내부 확인

Q18재구매 데이터가 있나?

누적 판매 1,600만 개와 리뷰의 '수년째 사용', '정착템' 표현이 재구매 지표입니다. 정량 재구매율은 내부 데이터 확인 후 회신드리겠습니다.내부 확인

팝업·오프라인 운영

Q19팝업 기간, 규모, 예산은?

성수 단독 팝업 기준 10~14일, 또는 무뷰페 부스 참여를 희망합니다. 규모와 예산은 무신사의 공간 조건을 받은 뒤 확정하겠습니다.내부 확인

Q20인테리어와 운영 인력은 누가 부담하나?

부스 제작, 운영 인력, 샘플은 브랜드 부담이 기본입니다. 무신사의 공간·집객 지원 범위를 알려주시면 분담안을 정리하겠습니다.

Q21측정 장비와 전문 인력이 있나?

피부 수분·유분 측정기와 두피 측정기를 준비하고, 교육받은 브랜드 직원이 상담합니다. 결과는 의학적 측정이 아닌 제품 추천용임을 안내합니다.내부 확인

Q22브랜드 자체 마케팅 계획은?

러닝·아웃도어 인플루언서 체험, 러닝 크루 사전 체험단, 제로이드 인스타그램 홍보를 계획합니다. 예산은 확인 후 회신드리겠습니다.내부 확인

Q23상설 진열 공간 요구 조건은?

스킨케어·더마 존 곤돌라 1면을 희망하고, 가능하면 남성 그루밍 동선에 핌프로브·루트힐 추가 진열을 요청드립니다.

물류·재고·거래 조건

Q24직매입과 위탁 중 무엇을 원하나? 초도 물량·반품은?

1단계는 반응 검증이 목적이라 위탁 또는 소량 직매입을, 2단계부터 직매입 확대를 희망합니다. 초도 물량과 반품 조건은 정식 회신드리겠습니다.내부 확인

Q25MFS와 무배당발 대응이 가능한가?

MFS 사용을 긍정적으로 검토하겠습니다. 무배당발 적용을 위한 입고 조건을 알려주시면 맞추겠습니다.

Q26유통기한과 시즌 재고 관리는?

유통기한이 충분히 남은 제품만 입고하고, 시즌 제품은 진열 교체 시점 기획전으로 소진합니다. 4종 모두 연중 수요가 있어 악성 재고 위험은 낮다고 봅니다.내부 확인

성과·KPI·마케팅 지원

Q27목표 지표의 산정 근거는?

성수 단독 팝업 기간 온라인 거래액 +240%, 메가스토어 뷰티존 입점 후 +35% 같은 무신사 공개 사례를 참고해 보수적으로 잡은 가안입니다. 무신사 내부 기준을 알려주시면 맞춰 조정하겠습니다.

Q28단계 조건을 못 채우면? 철수 기준은?

조건 미달 시 바로 확장하지 않고, 원인(제품·진열·가격)을 분석해 한 번 더 테스트한 뒤 판단합니다. 철수 기준은 무신사와 사전에 합의하겠습니다.

Q29할인·쿠폰 비용은 어떻게 분담하나?
