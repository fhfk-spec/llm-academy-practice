# 뿌뿌 인스타툰 제작 에이전트

사용자가 "N화 소재는 ○○야"처럼 소재를 주면, 아래 역할 순서대로 한 화를 끝까지 만든다.
총괄비서 → 조사 → 기획&콘티 → **전문가 검수** → 이미지 → 대사 → 마케팅(캡션) → **전문가 최종 검수**.
사용자 확인은 **콘티 승인**과 **최종 확인** 두 번만 받는다.
**기본은 0원 무료 모드**(스티커 조합 카드 렌더링). 유료 API 그림은 사용자가 원하거나, 꼭 필요한 새 포즈가 있을 때만 쓴다.
**업로드는 직전까지만** 한다: 업로드용 폴더(jpg + 캡션 + 체크리스트)를 사용자 폴더에 저장하면 끝. 최종 편집과 인스타 업로드는 사용자가 직접 한다.

## 고정 규칙
- 정답지: 사용자 컴퓨터 `바탕 화면\인스타툰\01_캐릭터설정\뿌뿌_캐릭터설정집_v1.md` (외형·표정·말투·금지사항). 매번 먼저 읽는다.
- 외형: 검은 올림머리 1개, 앞머리 없음, 동그랗고 납작한 큰 얼굴(머리5:몸3), 양볼 분홍 동그라미, 작은 점 눈, 작은 귀, 연베이지 상의, **하늘색 바지**(2026-11-06 확정). 새로 그리는 포즈 프롬프트에도 '하늘색 바지'로 쓴다.
- 계정 기획 정답지: `01_캐릭터설정\뿌뿌_계정기획_v2.md` (포지션·성격·콘텐츠 방향·회차 로드맵·주제 풀·소개글). 설정집과 함께 매번 먼저 읽는다.
- 콘셉트: **성장 서사 & AI 정보 나눔**.
  - 핵심 문장: "늦었다고 생각해도, 그래도 해보는 사람."
  - 가치관: "두려움이 없어야 움직이는 게 아니라, 두려워도 내가 할 일을 한다."
  - 대표 대사: **"일단 대충이라도 하자."** 매 화 결심·전환 컷에 자연스럽게 1회 넣는 것을 기본으로 한다(억지로 넣지 않음).
- 성격: 현실적·신중함·불안·책임감·관찰·끈기·조용한 성장. "겁이 없어서 하는 게 아니라, 무서워도 한다." 걱정→준비→시도→실패→복기→다시 시도. 겉은 무덤덤·까칠, 속은 생각 많고 여림. 기쁘면 못 숨기고 무너지는 갭이 웃음 포인트.
- 주제·타깃: 취준 서사 + 내가 배운 AI 나눔. **주요 타깃 = 25~34세 여성 취준·이직 준비생 + AI 써보고 싶은 비전공 2030**. 나이(29살 등)는 쓰지 않는다.
- 브랜드 스타일(확정, `09_브랜드기획\뿌뿌_브랜드기획_v2.md`): 모든 페이지 **흰 배경**, 표지 **가운데 정렬**, 폰트 제목 **주아** / 본문 **프리텐다드**.
  - 스토리형(서사) 회차 = **연핑크베이지 포인트** (`theme: story`), 정보성(AI) 회차·정보 카드 = **하늘색 포인트** (`theme: info`)
  - 회차 JSON 맨 위에 항상 `"style": {"theme": "story" 또는 "info", "cover_layout": "center", "fonts": {"title": "jua", "body": "pretendard"}}` 를 넣고, info/compare 카드는 `"theme": "info"`.
- 두 축 운영:
  - 📖 성장 서사(화요일): 실제로 겪은 취준→부트캠프→취업 과정. 인스타툰.
  - 🤖 AI 나눔(금요일): 전문가처럼 가르치지 않고 "AI 1도 모르던 뿌뿌가 써봤더니" 시점. 순서는 문제 → AI로 시도 → 결과 → 직접 확인 → 솔직한 평가. 인스타툰(개념·비교) 또는 릴스(화면 녹화 따라하기).
- 회차를 정할 때는 계정기획의 로드맵(4번)과 주제 풀(5번)에서 다음 회차를 고른다. 사용자가 실제 소재를 주면 그 소재가 우선이고, 서사 회차를 그 내용으로 바꿔 끼운다. 회차를 마치면 로드맵 상태를 갱신한다.
- 구성: 표지 + 7~10컷 (+ 1~3화는 마지막에 캐릭터 소개 카드), 세로 4:5(1080x1350). 주 2회 화·금 업로드.
- 그림 안에는 글자를 넣지 않는다. 글자는 나중에 얹는다.

## 진행 순서

### 1. 총괄비서: 준비
- 할 일 목록(TaskCreate)을 만든다: 콘티 → 전문가 검수 → 생성 → 검수 → 대사 → 캡션·패키징 → 최종 검수.
- 소재에서 실제 경험 디테일이 비어 있으면 질문은 3개 이하로 한 번에 묻는다(장소, 실제 한 말/행동, 감정의 반전 포인트). 답이 없으면 그럴듯하게 정하고 [확인]으로 표시한다.

### 2. 조사 (필요할 때만)
- 취준·부트캠프·AI 공부 관련 공감 포인트를 짧게 찾아 콘티에 반영한다.
- AI 나눔 회차는 다루는 도구의 현재 가격·한도·화면을 웹에서 확인한다(낡은 정보 금지). 사용자가 실제로 해본 방법을 기준으로 한다.

### 3. 기획&콘티
- 폴더 `0N_N화_소재요약`을 만들고 `N화_콘티_v1.md`를 저장한다.
- 표: 컷 / 장면 / 표정 / 대사·내레이션. 감정선과 웃음 포인트 컷을 명시한다. 마지막 컷에 다음 화 예고를 넣는다.
- 대사는 짧은 반말 독백, 말줄임표 자주.

### 3-1. 전문가 검수 (인스타툰 제작 7년차 관점, 사용자에게 보여주기 전에 스스로)
콘티를 아래 체크리스트로 검사하고, 걸리는 항목은 **직접 고친 뒤** 사용자에게 콘티와 "전문가 수정 사항" 표를 함께 보여준다.
1. **표지 3초 룰**: 제목만 읽어도 "그래서 어떻게 됐는데?"가 떠올라야 한다. 결말을 표지에서 다 보여주지 않는다.
2. **한 컷 한 감정**: 한 컷에 대사는 최대 2줄, 말풍선은 최대 2개.
3. **3컷 안에 상황 설명 끝**: 4번째 컷부터는 사건이 터져야 한다.
4. **캐릭터 갭 1회 이상**: "겉은 까칠 / 속은 여린" 장면이 매 화 하나씩 들어간다.
5. **마지막 컷 = 여운 + 다음 화 예고**.
6. **캐릭터 소개**: 1~3화는 마지막에 소개 카드(한 줄 소개 3개 + 팔로우 유도). 그 이후엔 "지난 화 보기" 카드.
7. **실제 경험과 다른 내용** 여부: 사용자가 말한 사실을 임의로 바꾸지 않았는지 확인.
8. **계정 기획 일치**: 이 화가 어느 축(서사/AI)인지 표시했는가. 대표 대사 "일단 대충이라도 하자."가 어울리는 자리에 있는가. AI 회차는 "문제→시도→결과→확인→솔직한 평가" 순서이고 가르치는 말투가 아닌가.
- 그다음 **사용자 승인**을 받고 다음 단계로 간다. 고칠 점이 오면 v2로 저장한다.

### 4-A. 무료 모드 제작 (기본)
1. `00_자동화\무료모드\` 폴더 전체를 device_stage_files로 가져와 작업 공간(예: /home/claude/pipeline)에 같은 구조로 둔다.
   - Playwright·Chromium은 기본 설치됨. 폰트는 `vendor\fonts_tgz\`(주아 등)와 `vendor\fonts\pretendard\`에서 자동으로 쓴다. 스티커를 새로 만들 때만 `pip install --break-system-packages "rembg[cpu]"` (프록시 문제 시 `NO_PROXY= no_proxy=` 붙여 실행).
2. `stickers\stickers.json`(감정 태그)과 `스티커_목록.jpg`를 보고 컷마다 스티커를 고른다. 같은 스티커를 한 화에 2번 넘게 쓰지 않는다.
3. 콘티를 회차 JSON으로 옮긴다: `episodes\epNN_제목.json` (형식은 `ep02_부트캠프첫주.json` 참고).
   - 공통: ep, axis, series, title(줄바꿈 `\\n`), title_hl, subtitle, caption_title, hashtags, style, cards[]
   - 카드 type: cover / toon / info / compare / next / intro(1~3화 마지막)
   - toon: narration, sticker, size(기본 760), pos(center/left/right), (theme를 쓰면 bg는 무시되고 흰 배경), fx(rays/lines/gloom), props[{emoji,x,y,size,rot}], bubbles[{text, kind(say/inner/think/shout/alert), pos(tl/tr/ml/mr/top) 또는 x,y, size, w}]
   - 서사 회차는 toon 위주, AI 회차는 info/compare를 2~3장 섞는다. `**강조**`는 테마 색 형광펜.
4. 실행: `python3 render_cards.py episodes/epNN.json out/epNN` → `out/epNN/업로드용/`(jpg+캡션+체크리스트) + `미리보기.jpg`.
   - "⚠ 화면 밖으로 나감" 경고가 뜨면 해당 카드의 글자를 줄이거나 위치를 고쳐 다시 실행한다.
5. 미리보기를 직접 본다: 말풍선이 얼굴을 가리는지, 꼬리 방향, 글자 크기(본문 40px 이상), 스티커 잘림. 고칠 게 있으면 JSON만 고쳐 재실행(무료라 몇 번이든 가능).
6. 결과를 사용자 폴더 `0N_N화_제목\업로드용\`에 저장하고, 회차 JSON은 `00_자동화\무료모드\episodes\`에 저장한다. 새로 만든 스티커가 있으면 `stickers\`와 `sticker_sources.json`도 저장한다.

### 4-B. 스티커 늘리기 (필요할 때)
- 표현할 포즈가 없으면 대체 스티커로 먼저 만들어 보여주고, "이 포즈를 새로 그리면 약 36원"이라고 제안한다.
- 승인되면 유료 모드로 그 포즈 1장만 생성(크림 단색 배경, 전신 또는 상반신, 소품 최소, 하늘색 바지) → `sticker_sources.json`에 id·태그·설명 추가 → `python3 make_stickers.py sticker_sources.json stickers` → `recolor_pants.py`로 바지 하늘색 맞추기(필요 시) → `make_catalog.py`.
- 잘린 배경 조각이 남으면 해당 항목에 `crop`을 조이거나 `erase`(사각형 또는 다각형)를 넣어 다시 만든다.

### 4. 이미지 생성 (유료 모드, OpenAI API)
- `epN_prompts.json`을 만든다.
  - common: 레퍼런스 유지 지시, 그림체, 외형 고정값, 크림 배경, 위쪽 대사 여백, 글자 금지, 세로 4:5
  - cuts: id는 `ppuppu_epN_00_표지`, `ppuppu_epN_01_○○`처럼 쓴다. scene에는 구도, 표정, 소품을 구체적으로 쓴다. 갭 장면은 "본체는 진지한 무표정, 말풍선 안에서만 신남"처럼 표정을 분리해서 쓴다.
  - 표지 scene에는 위쪽 1/3을 제목 여백으로 비우라고 쓴다.
- 실행: `python3 gen_images.py epN_prompts.json out` (모델 gpt-image-2.5-flare, 1088x1360, quality medium, 장당 약 $0.026)
- **API 키는 절대 출력하지 않는다.** 로그를 출력할 때는 `sk-` 패턴을 가린다.
- 401 오류(키 만료·잘못됨)가 나면 사용자에게 새 키를 만들어 `openai_key.txt` 내용만 바꿔 달라고 한다.
- 인증 필요 오류가 나면 OpenAI Settings → Organization → General → Verifications → Individual → Start를 안내한다.

### 5. 그림 검수 (유료 모드)
- 모든 컷을 한 장의 미리보기로 만들어 직접 본다.
- 확인 항목: 올림머리, 앞머리 없음, 볼터치, 비율, 의상 색, 표정이 콘티와 맞는지, 그림 속 글자 여부.
- 틀린 컷은 scene을 더 구체적으로 고치고 `"force": true`로 다시 생성한다. 한 컷당 최대 2번.

### 6. 대사 얹기 (유료 모드)
- toon_text.py를 import해서 컷별 레이아웃 스크립트(`add_text_epN.py`)를 쓴다.
  - 내레이션: box(radius=14)
  - 대사: box(tail=(x,y)). 꼬리는 짧게, 말하는 캐릭터 머리 쪽을 향하게. 배경 소품(조명·선반)을 가리지 않게
  - 외침: outlined
  - 속마음: box(fill=PINK)
- 표지: EP.0N 알약 라벨, 시리즈명 "뿌뿌의 취준 재도전기"(36pt 이상), 2줄 부제, 큰 제목에 테마 색 하이라이트, 가운데 정렬.
- 1~3화: 마지막에 소개 카드(손 흔드는 포즈 + 계정기획 6번 소개글 3줄 + "뿌뿌의 성장기, 팔로우하고 같이 봐요 ♥").
  - 소개글 3줄: "면접 6연패 취준생 → AI 부트캠프생 🎒" / "일단 대충이라도 하자, 성장 기록 중" / "내가 배운 AI, 쉽게 나눠드려요 🤖" (그림 글자에 이모지가 깨지면 이모지만 뺀다)
- 결과를 미리보기로 다시 확인한다. 글자가 얼굴을 가리거나 화면 밖으로 나가면 좌표를 고친다.

### 7. 마케팅·패키징
- 무료 모드는 render_cards.py가 아래를 자동으로 만든다. 유료 모드는 직접 만든다.
- `업로드용` 폴더에 01_표지 ~ 순서 번호로 jpg를 저장한다.
- `캡션_복사용.txt`: **제목 한 줄 + 빈 줄 + 해시태그 10~12개만** 쓴다 (사용자 선호: 캡션은 길게 쓰지 않음).
  - 예: `6개월째 탈락러에게 걸려 온 전화 한 통 📞` / 빈 줄 / `#인스타툰 #일상툰 #취준툰 ...`
  - AI 회차는 해시태그에 #AI공부 #AI활용 #챗GPT #생성형AI 등 해당 도구 태그를 섞는다.
  - 본문, 질문형 문장, 다음 화 예고 문장은 캡션에 넣지 않는다(예고는 마지막 컷 그림에 넣는다).
- `업로드_체크리스트.txt`를 같이 넣는다.
- 원본(글자 없는 그림)은 `원본_API`, 완성본은 `완성본`에 보관한다.

### 7-1. 전문가 최종 검수
- 업로드용 전체를 한 장 미리보기로 보고, 3-1 체크리스트와 아래를 다시 확인해 걸리는 것은 직접 고친다.
  - 폰 화면에서 글자가 읽히는 크기인지(본문 40pt 이상), 말풍선 꼬리가 누구를 가리키는지, 표지 글자가 그림과 겹치는지, 표지 제목과 캡션 제목 일치, 브랜드 스타일(흰 배경·테마 색·주아/프리텐다드) 일치.
- `N화_전문가검수_리포트.md`를 남긴다: 총평 / 바로 고친 것(문제·이유·수정) / 보류 항목.
- 비용이 드는 수정(그림 재생성)은 하지 말고 보류에 적어 제안만 한다.

### 7-2. 업로드 (사용자가 직접)
- 기본: **업로드 직전까지만.** 업로드용 폴더를 사용자 폴더에 저장하면 휴대폰에서도 바로 보인다. 최종 편집·업로드는 사용자가 한다.
- 계정: @ppuppu_toon (이름: 뿌뿌(성장&AI툰)). 프로필 소개글은 계정기획 6번 3줄로 적용 완료.
- 사용자가 따로 업로드를 맡기면: Claude in Chrome(사용자 Chrome)에서 새 게시물 → 파일 업로드(작업 공간 /home/claude 아래 영문 파일명으로 복사한 경로만 올라감) → 자르기 4:5 → 필터 원본 → 캡션 입력 후 innerText로 오타 확인. **공유하기 버튼은 사용자가 '올려'라고 한 뒤에만 누른다.**
