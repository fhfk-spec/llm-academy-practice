> 2026-11-06 확정 (v1 제안 → 사용자 결정 반영)

## 확정 사항
| 항목 | 확정 |
|---|---|
| 표지 공식 | **가운데 정렬** (EP 라벨 → 시리즈명 → 제목 2줄 + 키워드 형광펜 → 부제 → 캐릭터 1명) |
| 폰트 | 제목 **주아(Jua)** / 본문·말풍선 **프리텐다드(Pretendard) Bold** — 둘 다 무료 상업 사용 가능(OFL) |
| 배경 | **모든 페이지 흰색** |
| 메인 컬러 | **하늘색** — 뿌뿌 바지 + 정보성(AI 나눔) 콘텐츠 포인트 `#3F86C9` / 연한 톤 `#C4E0FA`·`#F0F7FE` |
| 서브 컬러 | **연핑크베이지** — 뿌뿌 상의 톤 + 스토리형 콘텐츠 포인트 `#D9765F` / 연한 톤 `#FFCFC0`·`#FFF4EF` |
| 회차별 색 | 스토리형 = 연핑크베이지 포인트 / 정보형 = 하늘색 포인트 (자동 제작 `theme: story / info`) |
| 캐릭터 | 바지 회청색 → **하늘색**으로 스티커 54종 일괄 변경. 상의는 기존 연베이지 유지 |
| 주요 타깃 | **25~34세 여성 취준·이직 준비생** + **AI 써보고 싶은 비전공 2030** |

### 상의 색에 대한 메모
상의 연베이지는 얼굴 피부색과 거의 같은 색이라 자동 일괄 변경이 불가능하다. 지금 색이 이미 "연한 베이지"라 그대로 두고, 핑크 기운을 더 원하면 새로 그리는 포즈부터 프롬프트에 "연핑크베이지 상의"로 적용한다.

### 폰트 비교 결과
| 후보 | 인상 | 판단 |
|---|---|---|
| **A 주아 + 프리텐다드** | 동글동글 귀여움 + 본문은 깔끔하게 잘 읽힘 | ✅ 채택: 뿌뿌 그림체와 가장 잘 맞음 |
| B 도현 + 고운돋움 | 단단하고 또렷 | 제목이 다소 딱딱 |
| C 개구(손글씨) | 일기 감성 | 자간이 벌어져 폰에서 가독성 떨어짐 |
| D G마켓 산스(기존) | 무난, 광고 느낌 | 개성 약함 |

## 1. 팔로워 20만+ 인스타툰에서 뽑은 표지 공식
| 계정 | 팔로워 | 표지 구성 |

| 미코 @mico.144 | 24.5만 | 흰 배경, **가운데 제목 + [N편]** 번호, 흑백 라인 인물 2명 |
| 짤툰 @jjaltoon | 20.3만 | 릴스 중심, **캐릭터 얼굴 초근접 + 강한 원색** 배경 |
| 펀자이씨 @punj_toon | 20.3만 | 손글씨 한 문장 + 펜화, 시리즈 공지는 컬러 배너 |
| (참고 10만대) 이삼십·이연필 | 12.9만·11.4만 | 상단 **큰 제목 띠**, 과장 표정 클로즈업, 시리즈 번호 ① |

**공통 공식 (5요소)**
1. **위 1/3 = 제목 2줄**: 질문형("이게 맞나요?") 또는 결과를 숨긴 감정형("몸이 먼저 항복했다")
2. **시리즈 표시**: 시리즈명·회차 번호(EP.02 / [2편]) → 정주행 유도
3. **아래 2/3 = 캐릭터 1명, 과장 표정** (얼굴이 화면의 30~50%)
4. **배경 단색 1개 고정** → 프로필 그리드가 한 브랜드처럼 보임
5. **키워드 하나만 강조** (형광펜·색 글자)

**뿌뿌 표지 3종 (자동 제작에 반영 완료)**
- **A 공감형** (서사 기본): 왼쪽 정렬 큰 제목 + 과장 얼굴, 코랄 배경
- **B 시리즈형** (연재물): 가운데 정렬 제목 + [N편], 코랄 배경
- **C AI 정보형**: "🤖 뿌뿌의 AI 나눔" 라벨 + 가리키는 포즈, 블루 배경
→ 서사는 코랄, AI는 블루로 번갈아 올라가면 피드에서 **회차 종류가 색으로 바로 구분**된다 (`피드_그리드_미리보기.jpg`)

## 3. 타깃 분석
※ 아직 팔로워가 적어 실제 데이터가 아닌 **가설**. 프로페셔널 계정 인사이트에서 팔로워 연령·성별이 보이기 시작하면(팔로워 약 100명 이상) 다시 검증한다.
- 근거: 한국 인스타그램은 **25~34세가 가장 큰 연령대, 여성이 다수**(Statista, 2026.9). 월 사용자 약 2,800만 명으로 역대 최대(와이즈앱).

| 구분 | 누구 | 상황 | 니즈 |
|---|---|---|---|
| **핵심** | 25~34세 여성 취준생·이직 준비생 | 서류·면접 탈락 반복, 부트캠프·국비 고민 | "나만 이런 거 아니구나" 공감, 다시 해볼 용기 |
| **핵심** | AI 써보고 싶은 비전공 2030 | ChatGPT는 써봤지만 업무·포트폴리오 활용은 막막 | 초보 눈높이 따라하기, 실제 비용·한도 같은 현실 정보 |
| 2차 | 20대 초중반 대학생·사회초년생 | 진로 불안, 첫 직장 | 미리 보는 취준 현실, 가벼운 웃음 |
| 2차 | 30대 중후반 커리어 전환·재취업 | 늦었다는 불안 | "늦었다고 생각해도 해보는 사람" = 뿌뿌 핵심 문장과 직결 |

**니즈 → 콘텐츠 연결**
1. **공감·위로** → 서사 회차 (탈락, 통장, 비교) → 댓글·공유 유도
2. **대리 성취감** → 작은 성공 컷(추가합격, 완성) → 팔로우 동기
3. **실용 정보** → AI 회차 (따라하기·비용·전후 비교) → **저장** 유도
4. **가벼운 소비** → 1분 안에 읽는 8~11컷, 표지 3초 룰
5. **동기부여** → 대표 대사 "일단 대충이라도 하자." 반복으로 계정 슬로건화
