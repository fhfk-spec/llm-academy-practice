# 뿌뿌 인스타툰 무료 자동 제작 (0원 모드)

## 한 줄 요약
**회차 JSON 1개 → 명령 1번 → 업로드 직전 패키지(jpg + 캡션 + 체크리스트 + 미리보기)**
그림을 매번 새로 그리지 않고, 이미 있는 뿌뿌 그림을 **스티커**로 만들어 카드 틀에 조합합니다. 비용 0원.

## 흐름
| 단계 | 누가 | 무엇 |
|---|---|---|
| 1. 소재 | 사용자 | "N화 소재는 ○○야" (실제 겪은 일) |
| 2. 콘티 → 회차 JSON | 클로드 | 계정기획(서사/AI 축)에 맞춰 카드 8~10장 설계 + 7년차 전문가 검수 |
| 3. 승인 | 사용자 | 콘티 OK |
| 4. 렌더링 | 자동 | `python3 render_cards.py episodes/epNN.json out/epNN` |
| 5. 검수 | 클로드 | 미리보기 확인 → 글자 넘침·겹침 수정 |
| 6. 폴더 저장 | 클로드 | `0N_N화_제목\업로드용\` (OneDrive라 휴대폰에서도 바로 보임) |
| 7. 최종 편집·업로드 | **사용자** | 인스타에서 직접 |

## 파일
| 파일 | 역할 |
|---|---|
| `render_cards.py` | 카드 렌더러 (HTML+CSS → Playwright로 1080x1350 jpg) |
| `make_stickers.py` + `sticker_sources.json` | 그림에서 뿌뿌만 잘라 스티커로 저장 (rembg, 무료·오프라인) |
| `make_catalog.py` → `스티커_목록.jpg` | 지금 쓸 수 있는 스티커 한눈에 보기 |
| `stickers/` | 스티커 54종 + `stickers.json`(이름·감정 태그) |
| `episodes/` | 회차 JSON 모음 (예시: `ep05_한도초과.json`) |
| `vendor/twemoji-svg-15.0.0.tgz` | 소품 이모지 그림 (Twemoji, CC-BY 4.0 무료) |
| `fonts/` | G마켓 산스 (무료 상업용 폰트) |

## 카드 종류
- `cover` 표지 · `toon` 툰 컷(내레이션+스티커+말풍선) · `info` AI 정보(번호 목록+팁 박스)
- `compare` 비교(무료 vs 유료 등) · `next` 다음 화 예고 · `intro` 뿌뿌 소개(1~3화)
- 말풍선 `kind`: `say` 대사 / `inner` 속마음(분홍) / `think` 생각 / `shout` 외침(큰 글씨) / `alert` 알림창
- `**강조**` → 분홍 형광펜, 이모지 → 자동으로 컬러 그림
- 배경 `bg`: cream / pink / night / mint / yellow / gray, 효과 `fx`: rays(집중광) / lines(집중선) / gloom(우울)

## 스티커 늘리기 (선택)
- 새 포즈가 필요하면: 유료 API로 그 장면 1장만 생성(약 36원) → `sticker_sources.json`에 추가 → `make_stickers.py` 실행.
  한 번 만든 스티커는 계속 무료로 재사용됩니다.
- 사용자가 직접 그린 그림·다른 AI로 만든 그림도 같은 방법으로 추가 가능.

## 새 작업 공간에서 처음 실행할 때 (클로드가 알아서 함)
```
pip install --break-system-packages "rembg[cpu]"   # 스티커 만들 때만 필요
# Playwright·Chromium은 기본 설치되어 있음
```
