# CJ LLM아카데미 실습 제작물

CJ LLM아카데미 실습 과정에서 Claude로 만든 결과물이에요. HTML 파일은 다운로드해서 브라우저로 열면 바로 볼 수 있어요.
이 저장소는 매일 자동으로 정리·업데이트돼요.

## 01. 제로이드 × 무신사뷰티 입점 제안

신입 영업 MD 입장에서 뷰티 브랜드 '제로이드'를 무신사뷰티(성수 팝업·온라인)에 입점시키는 제안서를 만든 실습이에요.

| 파일 | 내용 |
|---|---|
| `실습_1일차.html` ~ `실습_3일차.html` | 일자별 실습 기록 |
| `제안서_3차.html` | 최종 입점 제안서 (3차 수정본) |
| `입점제안_요약.html` | 한 장 요약 |
| `제로이드x무신사뷰티_성수.html` | 성수 팝업 제안 |
| `미팅_준비노트.html` | MD 미팅 준비 노트 |

## 03. 뿌뿌 인스타툰 제작 AI 에이전트

소재 한 줄을 주면 콘티 → 그림 → 검수 → 대사 → 캡션까지 인스타툰 한 화를 업로드 직전까지 만드는 에이전트예요.

| 폴더 | 내용 |
|---|---|
| `00_에이전트_스킬/SKILL.md` | 에이전트 지시서 (Claude 스킬) |
| `00_에이전트_역할구조_v1.md` | 역할 분담 설계 (총괄비서·조사·기획·이미지·마케팅) |
| `00_자동화/` | 그림 생성(OpenAI API), 글자 얹기, 0원 무료 모드(스티커 카드 렌더링) |
| `01_캐릭터설정/` | 캐릭터 설정집, 계정기획 |
| `02_1화` ~ `11_번외` | 회차별 콘티, 완성본, 업로드용 이미지·캡션, 검수 리포트 |

- 기획서(문서): https://claude.ai/artifact/MciNvqVMyDTjoM9wZ2cKta
- API 키, 폰트 파일, 원본 생성 이미지는 올리지 않아요.
