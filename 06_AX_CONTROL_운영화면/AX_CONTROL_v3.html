판정 기준

OT 자료 확인
  • 수업 시간 09:00~18:00, 점심 13:00~14:00 제외 하루 8시간
  • 정상 출석 09:10까지 입실 (9시 전 입실은 언제든 가능) · 09:11부터 지각
  • 조퇴 17:50 전에 퇴실 · 외출 수업 중 10분 이상 자리 비움
  • 지각·조퇴·외출 3회 = 결석 1일. 하루에 두 가지가 겹치면 2회로 셉니다.
  • 그날 4시간 미만 수강이면 결석 (8시간의 50% 미만). 4시간 이상이면 지각·조퇴·외출로 인정
  • 수료 전체 교육일수의 80% 이상 출석 = 결석 20% 이하
  • 참여수당 단위기간(10/26부터 한 달씩) 출석률 80% 이상이면 월 50만 원
  • 나머지 횟수 단위기간마다 3회를 채우지 못한 1~2회는 수당 계산에서 빼고, 수료 판정에서는 전체를 합산
  • 제적 단위기간 결석 50% 이상, 또는 전체 결석이 20% 초과
  • 공가 예비군·채용시험·결혼·사망·출산·질병(전체 훈련일수의 10%, 5일) 등은 증빙을 LMS로 내면 출석 인정. 이 계산기에는 결석으로 넣지 마세요.

Operating system / team rules

일은 맡기고,
기준과 근거는 지킨다.

공통 규칙 CLAUDE.md 요약. 2026-11-12에 ChatGPT 제작물에서 좋은 원칙을 골라 합쳤습니다.

01 · 허브 앤 스포크

총괄 PM만 호출·취합·조정·보고. 에이전트끼리 부르지 않음.

02 · 파일이 기억

지시문 6요소, handoffs/ 인수인계서, decisions.md를 먼저 읽음.

03 · 남이 검토

정해진 검토자를 새로 호출. qa-reviewer는 읽기 전용 최종 관문.

04 · 근거 ID와 태그

R·N·D 근거, [확인]·[추론]·[가설]·[미확인]. "사용자 설명"과 "공식 문서" 구분. 합침

05 · 경보 ≠ 처분

위험 표시는 지원 신호. 처분 안내는 기관 확정 뒤. 합침

06 · 데이터 정직성

데이터 없음 ≠ 0. 목표선 ≠ 실적. 원본은 읽기 전용, 정정은 이력과 함께. 합침

07 · 발송 안전

초안 기본. 위임·도구가 있어도 사용자 확인 후, 개인별·숨은참조, 발송 기록, 중복 방지 키. 합침

08 · 개인정보

기관 → CJ는 집계만(C안), 0 / <5 / n. 실명은 raw/에만, git 제외.

09 · 공정성

소수 사례 일반화 금지. 경제력·개인 사정을 선발 기준으로 쓰지 않음. 진술과 관찰 분리. 합침

Prototype / morning attendance bot

9시에 먼저 묻는
출결 알림 봇.
