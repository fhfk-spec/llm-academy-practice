# CJ LLM아카데미 실습 제작물

CJ LLM아카데미 실습 과정에서 Claude로 만든 결과물이에요. HTML 파일은 다운로드해서 브라우저로 열면 바로 볼 수 있어요.

## 01. 제로이드 × 무신사뷰티 입점 제안

신입 영업 MD 입장에서 뷰티 브랜드 '제로이드'를 무신사뷰티(성수 팝업·온라인)에 입점시키는 제안서를 만든 실습이에요.

| 파일 | 내용 |
|---|---|
| `실습_1일차.html` ~ `실습_3일차.html` | 일자별 실습 기록 |
| `제안서_3차.html` | 최종 입점 제안서 (3차 수정본) |
| `입점제안_요약.html` | 한 장 요약 |
| `제로이드x무신사뷰티_성수.html` | 성수 팝업 제안 |
| `미팅_준비노트.html` | MD 미팅 준비 노트 |

## 02. 맞춤식단

비건·고단백 식단을 하거나 음식 알러지가 있어도 외식할 수 있도록 서울·대전의 맞는 식당을 골라 둔 안내 사이트예요.
